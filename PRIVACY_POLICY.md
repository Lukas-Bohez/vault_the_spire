# VaultTheSpire Privacy Policy

Last updated: 2026-03-24

## 1. Introduction
VaultTheSpire is built for local secure storage and private peer-to-peer transfer. We are committed to your privacy and data security.

## 2. Data we collect
- VaultTheSpire does not collect personal data or analytics by default.
- No user identity is sent to our servers.
- Peer-to-peer connections are direct between your client and your selected peers.
- No telemetry, tracking, advertising, or third-party analytics libraries are used.

## 3. Permissions
- Android storage/media permissions are requested only when the user selects file import/export operations.
- Network permission is required for P2P and torrent connectivity.
- Optional OS file access is used only for user-approved file operations.

## 4. Encryption
- Local data is encrypted with your passphrase.
- Transfers are end-to-end encrypted (E2EE) between peers.

## 5. Third-party plugins/libraries
- Uses standard Flutter packages (`cryptography`, `sqlcipher_flutter_libs`, `sqflite`, etc.).
- No external data collection from these packages is performed.

## 6. Data Safety declarations for Google Play
- `No personal data` collected
- `No location` data collected
- `No device identifiers` recorded (beyond preexisting OS-level App Bundle behavior)
- `No data shared` with third-party services

For privacy questions, contact: privacy@quizthespire.com.
