# Data Safety Summary for Google Play

## Data categories
- Personal info: No
- Payment info: No
- Location: No
- Contacts: No
- Files and media: Yes (user-selected) - local only, no raw export without permission
- Camera: No
- Microphone: No (voice chat uses WebRTC permissions via peer request where required)
- Health & fitness: No
- Other sensitive data: No

## Data uses
- App functionality: Local vault encryption/decryption, P2P connection management, file transfer. No backend data collection.
- Analytics: None.
- Advertising: None.

## Data sharing
- With third parties: No.
- With service providers: No.

## Security practices
- Local data encrypted using SQLCipher and cryptography packages.
- No tracking or fingerprinting.
- All permissions are optional and user-consented.
